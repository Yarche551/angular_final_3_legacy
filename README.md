# что сделано

- На главной баннеры открываются без одновременного показа всех слайдов.
- На странице товара изображение и блок покупки остаются на месте при переключении вкладок.
- На коротких страницах подвал расположен у нижней границы окна.
- Мини-корзина закрывается при переходе в корзину. Счётчик и сумма обновляются сразу при добавлении, удалении и изменении количества товаров. После удаления последнего товара открытая страница корзины показывает, что она пуста.
- Карточки одновременно показывают все подходящие плашки «Новинка», «Хит» и «Акция».
- При сортировке по популярности панель фильтров на компьютере остаётся раскрытой. На телефоне настройки цены работают отдельно от сортировки. При смене категории текущий список виден до загрузки новых товаров.
- Для неизвестных адресов добавлена страница 404 со ссылкой в каталог. Шаблоны страниц собраны в одной папке.

## Работа с ИИ

ИИ помог разобраться, где обновляются каталог и корзина, и доработать четыре функции.

- `loadProducts` сохраняет текущий список до получения новых товаров и отменяет устаревшие запросы.
- `updateCartSummary` синхронизирует счётчики и сумму.
- `renderProductCard` выводит все подходящие плашки.
- `render` закрывает мини-корзину при навигации и показывает страницу 404 для неизвестного адреса.
